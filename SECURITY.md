# Security Policy

## Scope

This repository is a research reference implementation using entirely synthetic data. It performs no network requests, stores no credentials, and processes no real personal data or AI system outputs. There is no production deployment surface.

## Reporting a Vulnerability

If you discover a security issue in this codebase (e.g., a dependency vulnerability, unsafe deserialization, or path traversal in a CLI script), please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the maintainer at [royz.saurabh@gmail.com](mailto:royz.saurabh@gmail.com) with the subject line `[RCEA] Security Report`.
3. Include a description of the issue, steps to reproduce, and any suggested remediation.

You will receive an acknowledgement within 5 business days. Confirmed vulnerabilities will be addressed in a patch release and credited in `CHANGELOG.md` unless you prefer to remain anonymous.

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |
